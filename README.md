# Million Website

الصفحة الرئيسية لمنصة **Million** — نظام تشغيل أعمال يساعد المؤسس الواحد على إنشاء وإدارة عدة شركات ومتاجر بالذكاء الاصطناعي.

## الفكرة

بدل إدارة أدوات متفرقة، يبدأ المستخدم بوصف فكرته في مربع واحد. يقوم Million بتحويلها إلى شركة وهوية ومتجر، ثم يوزّع التشغيل على وكلاء ذكاء اصطناعي متخصصين.

## التشغيل محليًا

لا يحتاج المشروع إلى بناء أو تثبيت حزم:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## الاختبارات

```bash
npm test
```

تتحقق الاختبارات تلقائيًا مع كل تحديث عبر GitHub Actions.
